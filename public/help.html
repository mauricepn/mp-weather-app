How to use this app


Use this app to check instant weather updates anywhere in the world.

How to use it ? : Enter a town, city, state, or country in the search input and click the search button to view current weather metrics instantly.

API USAGE NOTE: This app is completely free. It connects to external weather services that limit how many free requests can be made each month. If those limits are hit during a high-traffic month, the app might temporarily stop showing weather updates until our free balance automatically resets at the start of the next calendar month.
